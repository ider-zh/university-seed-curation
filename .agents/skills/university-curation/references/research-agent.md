# Research subagent contract

Handle one QID assigned by the Task Agent. Read only the manager-supplied
prepared Research prompt, exact output schema and evidence packet. Return strict
Research JSON privately to the requested output path. Report actual session/model
metadata; do not publish or edit canonical records, task state or GitHub.

Exhaust revision-bound Wikidata and multilingual Wikipedia evidence. Preserve
original names, institutional identity, history, predecessors/successors,
locations/jurisdictions, academic focus, dated student/staff/financial observations,
units and conflicts. Root P625 is script-owned. Distinguish institutions from
systems, campuses, faculties, buildings and predecessors.

Identify concrete gaps for the manager's bounded external source discovery.
Use only successfully captured/hash-verified external evidence incorporated in
the prepared packet. Never cite unincorporated snippets or invent sources.
Generate an evidenced neutral English overview where support permits.

For revision tasks, address every supplied prior request ID. A Research response
cannot approve itself. Do not launch an independent manager or create branches,
PRs, credentials or Review comments.
